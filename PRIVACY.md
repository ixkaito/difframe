# Privacy Policy

Difframe does not collect, store, transmit, or share any user data.

- All settings (presets and options) are stored locally in your browser via the extension storage API and never leave your device.
- In image mode, pasted or dropped images are also stored locally in your browser.
- Difframe has no server and makes no network requests of its own. The only network activity is your browser loading the reference URL you specify, directly in an iframe.
- No analytics, no tracking, no third-party services.

If you have any questions, please open an issue at
<https://github.com/ixkaito/difframe/issues>.

---

# プライバシーポリシー

Difframe はいかなるユーザーデータも収集・保存・送信・共有しません。

- すべての設定（プリセット・オプション）は拡張機能のストレージ API によりブラウザ内にのみ保存され、デバイスの外に出ることはありません。
- 画像モードで貼り付け・ドロップした画像も同様にブラウザ内にのみ保存されます。
- Difframe は自前のサーバーを持たず、独自の通信を一切行いません。発生する通信は、指定した参照 URL をブラウザが iframe として直接読み込むものだけです。
- アナリティクス・トラッキング・サードパーティサービスは使用していません。

ご質問は <https://github.com/ixkaito/difframe/issues> までお寄せください。
